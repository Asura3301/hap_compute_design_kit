# Integration with HAP Compute
The coding agent coordinates two independently installed skills. Consult the current Compute release and its application reference before editing a connected project. Compute selects or recovers the target environment and initializes its app template. Apply this kit to the resulting frontend. Use the existing server adapter for data. Keep sensitive configuration server-side and enforce permissions there.

Hand back the changed asset paths, intended user journey, required API responses and local checks. The Compute workflow owns packaging, review, deployment, version retention and verification of the hosted app. Login source bundles and legacy login CSS have their own Compute workflow. Route requests for those surfaces there before changing any assets.

When the Compute skill changes, compare its documented frontend layout, API routing, authentication and template contracts with this reference, then smoke-test the starter in a disposable project before declaring compatibility.
